# Arduino Sketches

Give every Arduino sketch its own folder, and give the folder and `.ino` file
exactly the same name. For example:

```text
arduino/
  thermistor_serial/
    thermistor_serial.ino
  tec_manual_control/
    tec_manual_control.ino
  tec_python_control/
    tec_python_control.ino
```

Keep the version used for an experiment identifiable. Do not accumulate files
named `final`, `final2`, or `newest`.
