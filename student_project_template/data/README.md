# Data

Create a subfolder for each experiment or module only when data are collected.
For example:

```text
data/
  module_04_open_loop/
  module_05_p_control/
```

Inside each data folder, record the date, apparatus configuration, Arduino
sketch, Python program, units, column meanings, and relevant Git commit.

Commit small example and processed data needed to reproduce results. Ask before
committing very large raw data files.
